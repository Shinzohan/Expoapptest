# Expo App Assignment

This is a React Native application built using [Expo](https://expo.dev/) for mobile platforms. The app is designed as part of an assignment and **demonstrates the use of Firebase Cloud Messaging (FCM) to send push notifications.**

## 📱 Features

- Cross-platform support (iOS & Android)
- Modern and responsive UI
- **Push notifications using Firebase Cloud Messaging (FCM)**
- Easy to install and run

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or higher)
- [Expo Go](https://expo.dev/client) app installed on your mobile device
- Firebase account & project setup (for push notifications)
- (Optional) [Expo CLI](https://docs.expo.dev/get-started/installation/) installed globally
